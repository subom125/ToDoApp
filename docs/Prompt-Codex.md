# Prompt giao cho Codex

## Yêu cầu ban đầu

> Giờ tôi bắt tôi làm bài này trị giá 4 điểm: yêu cầu có backend (cơ sở dữ liệu, kiến trúc dữ liệu,...) hãy thiết kế cho tôi TODO App: chương quản lý các task cá nhân
>
> Kết quả yêu cầu: Code đưa lên GitHub với README mô tả chức năng hệ thống.
>
> Chức năng: (1) Hiển thị các task trong ngày hôm nay, có thể search, filter. (2) Thêm sửa xóa task. (3) Trang thống kê, có thể đưa những data mock vào.
>
> GUI giao diện, Prompt cho Codex Vibe code: 1.5 điểm. Chương trình không có cơ sở dữ liệu: 1 điểm. Database: 0.5 điểm. Chương trình full: 1 điểm và cần chụp ảnh gì vào Word theo từng mục để minh chứng.

## Prompt tái tạo

> Xây TODO App quản lý công việc cá nhân, giao diện tiếng Việt, dùng Node.js, HTML/CSS/JavaScript và SQLite. Màn hình mặc định hiển thị việc đến hạn hôm nay theo giờ Việt Nam, hỗ trợ tìm theo tên và lọc theo trạng thái, ưu tiên. Cho phép bật xem mọi ngày, thêm, sửa, xóa có xác nhận. Tạo trang thống kê tổng, đếm theo trạng thái và tỷ lệ hoàn thành, có nút bật dữ liệu mẫu. Tạo chế độ chạy dùng RAM để minh chứng chương trình không có cơ sở dữ liệu. Cung cấp schema, mô tả API, README hướng dẫn chạy và kiểm thử, cùng mẫu Word hướng dẫn các ảnh cần chụp theo thang 4 điểm.
